# Datenschutzhinweis zur Software backsAIde (Geräte-Lizenz)

Entwurf, Stand 06.11.2026

**Kurzfassung:** Das Programm sendet von sich aus keine Daten an die Rechteinhaberin oder an Dritte. Es gibt keine Telemetrie, keine Nutzungsstatistik, keine automatische Update-Abfrage, keine Lizenz-Abfrage über das Internet und keine Werbung.

- **Wo liegen deine Daten?** Ausschließlich auf dem Server, den du selbst betreibst (Raspberry Pi, PC, Mietserver). Auf deinen Geräten wird nichts gespeichert: Notizen und Token liegen nur im Arbeitsspeicher der geöffneten App und sind nach dem Schließen weg. Auf dem Server liegen die Notizen mit AES-256-GCM verschlüsselt. Die Rechteinhaberin hat keinen Zugriff darauf und kann verlorene Tokens nicht wiederherstellen.
- **Geräte-Lizenz:** Damit der Server Geräte unterscheiden kann, erzeugt jede App eine zufällige Geräte-Kennung (die einzige Information, die im Browser bleibt, zusammen mit der Server-Adresse) und leitet einen groben Gerätenamen aus dem Systemtyp ab (zum Beispiel „Windows“ oder „Android-App“). Beides wird bei jeder Anfrage an deinen eigenen Server geschickt und dort in der verschlüsselten Datei `.backsaide/license.bin` gespeichert (erstes und letztes Auftreten, Teststatus, eingelöste Codes). Zähler und eingelöste Codes liegen zusätzlich verschlüsselt im Schlüssel-Tresor des Servers, damit die Lizenz nach einem Datenverlust wiederherstellbar ist. Die Kennung ist zufällig und enthält keine Hardware- oder Netzwerkdaten. Sie bleibt auf deinem Server. Die Rechteinhaberin erfährt sie nur, wenn du sie ihr zur Erstellung eines Freischaltcodes selbst mitteilst. Rechtsgrundlage für deine Daten auf deinem Server bist du als Betreiber; beim Kontakt mit der Rechteinhaberin ist es Art. 6 Abs. 1 lit. b DSGVO (Vertrag, Kauf eines Codes).
- **Was verarbeitet der Server sonst?** Deine Notizen und Anhänge, die Benutzernamen und die Hashes der Zugangs-Tokens sowie Ereignis-Protokolle des Betriebssystems (z. B. IP-Adressen verbundener Geräte im Systemprotokoll). Verantwortlich dafür bist du als Betreiber des Servers. Gibst du Zugang an andere Personen, sind die Pflichten nach DSGVO deine.
- **Token und Freischaltcode:** Der Server prüft beides. Den Freischaltcode speichert die App nirgends, sie reicht ihn nur weiter. Das Token gibst du bei jedem Start der App neu ein (dein Passwortmanager kann es einfügen). Die App speichert weder Token noch Notizen im Browser-Speicher. Ungesicherte Änderungen gehen verloren, wenn du die App ohne Verbindung zum Server schließt.
- **KI-Anbindung (MCP):** Verbindest du Claude oder ein anderes KI-System mit deinem Server, fließen Notizen an dieses System. Dafür gelten dessen Datenschutzbedingungen. Das entscheidest du.
- **Download:** Die Programme werden über GitHub bereitgestellt. Dabei verarbeitet GitHub technische Daten (z. B. IP-Adresse). Siehe die Datenschutzerklärung von GitHub.
- **Kauf eines Codes:** Schreibst du der Rechteinhaberin, um einen Code zu kaufen, verarbeitet sie deine E-Mail-Adresse, die Server-ID und die Geräte-Kennung nur, um den Code zu erstellen und die Bestellung abzuwickeln. Rechnungsdaten werden nach den gesetzlichen Aufbewahrungsfristen gespeichert. Du hast die Rechte auf Auskunft, Berichtigung, Löschung, Einschränkung, Datenübertragbarkeit und Beschwerde bei einer Aufsichtsbehörde.
