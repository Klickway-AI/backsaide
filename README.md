# backsAIde (Geräte-Lizenz)

Selbst gehostete Markdown-Notizen mit Sync und KI-Anbindung (MCP). Alles verschlüsselt, Anmeldung per Token, kein Phone-Home.

**Lizenzmodell:** Ein Gerät ist dauerhaft kostenlos. Jedes weitere Gerät läuft 14 Tage zum Testen und ist danach gesperrt, bis ein Freischaltcode eingegeben wird (kostenpflichtig). Deine Notizen bleiben auf dem freien Gerät immer nutzbar. Details: `LICENSE.txt`.

## Downloads (Release v0.4.3)
- Server: Linux (x64, arm64, armv7 für Raspberry Pi), Windows (macOS folgt, sobald GitHub einen Mac-Rechner frei hat)
- Apps: Android (APK), Windows-Desktop, iPhone und iPad über Safari (siehe unten)
- Prüfsummen: `SHA256SUMS`

Anleitung steht in der jeweiligen `LIESMICH-*.txt` im Paket. Dieses Repo enthält nur fertige Programme und Texte, keinen Quellcode.

Freischaltcode anfordern: backsAIt@mail.de (bitte Server-ID und Geräte-Kennung angeben). Impressum: `IMPRESSUM.md`. Entwurf der Bedingungen, keine Rechtsberatung.

## iPhone und iPad
Es gibt keine eigene iOS-App (dafür braucht es ein Apple-Entwicklerkonto). Die Oberfläche läuft im Safari und lässt sich wie eine App ablegen: Adresse deines Servers im Safari öffnen, Teilen-Symbol, „Zum Home-Bildschirm“. Das Token gibst du bei jedem Start neu ein; auf dem Gerät wird nichts gespeichert. Das iPhone zählt wie jedes andere Gerät für die Geräte-Lizenz.

## Datenschutz auf dem Gerät
Die Apps speichern weder Token noch Notizen im Browser oder auf dem Handy. Alles liegt nur auf deinem Server, verschlüsselt.
